# devBuddy 🚀

Your AI-powered personalized software engineering mentor.

## Project Structure

- `frontend/`: Next.js (TypeScript, Tailwind CSS)
- `backend/`: FastAPI (Python)

## Getting Started

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```
